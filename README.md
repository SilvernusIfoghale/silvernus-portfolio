# SilverDev Portfolio

A modern, responsive portfolio website showcasing my projects and technical expertise. Built with React, Tailwind CSS, and Framer Motion.

## 🚀 Demo

[Live Preview](https://silvernus-portfolio.vercel.app/)

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion, SCSS, Bootstrap, Shadcn/UI
- **Mobile:** Flutter, React Native, Dart
- **Backend & Database:** Node.js, MongoDB, Firebase
- **Tools:** Git, GitHub, Vite

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/silvernus-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
